Lav Parfum V15 - полный сайт

Изменения:
- Использованы все 6 присланных исходных изображений для 5 ароматов (одно исходное изображение - коллаж с нотами, из него взят только флакон).
- Обновлены изображения Louis Vuitton Imagination, Louis Vuitton Attrape-Rêves, Louis Vuitton Symphony, Bouge Pathos, Parfums de Marly Delina Exclusif.
- Флаконы не перерисовывались и не изменялись по форме или содержимому; изменены кадрирование, масштаб и фон.
- У Louis Vuitton Symphony удалён интерфейс со скриншота, включая чёрные полосы.
- Блок «Обмена и возврата нет» уменьшен на компьютере.
- Убрана дополнительная юридическая приписка из блока условий покупки.
- Теплее оформление, мягче скролл и появления элементов, есть поддержка prefers-reduced-motion.

Установка через GitHub Desktop: распаковать в папку репозитория с заменой, Commit to main -> Push origin.
