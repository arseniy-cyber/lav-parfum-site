# Лав парфюм - версия 10

## Что изменилось

1. Настоящая многостраничная структура. Общие страницы: `index.html`, `catalog.html`, `about.html`, `selection.html`, `quiz.html`, `info.html`, `contacts.html`, `privacy.html`, `admin.html`. Для каждого из 121 отображаемого аромата создан собственный HTML-файл `product/NNN.html`. Все ссылки относительные; сайт можно размещать в корне домена или в подпапке GitHub Pages.
2. Карточки каталога и подборка товаров на главной теперь являются настоящими HTML-ссылками. Клик колёсиком, Ctrl/Cmd + клик открывают их в новой вкладке стандартными средствами браузера.
3. При переходе из каталога в карточку сохраняются позиция прокрутки, строка поиска, бренд, категория и количество показанных товаров. Ссылка «← Коллекция» в карточке возвращает к сохранённому месту, а системная кнопка «Назад» браузера также учитывается.
4. Исходное фото №015 Louis Vuitton Imagination восстановлено целиком из оригинала: видны верх крышки и основание, без среза стекла. В каталоге сохранены все 121 подтверждённые фотографии.
5. Страница «Подбор аромата» стала компактнее. Левая часть следует за прокруткой на компьютере; на небольших устройствах идёт обычным блоком перед формой.
6. Два новых фоновых изображения по эстетике пользовательских исходных фотографий поставлены на обложки «С любовью к деталям» и «Мы рядом». Декоративное оформление отделено от фотографий товаров.
7. «Оплата и доставка» оформлены в тонкие светлые карточки; кнопки Telegram и Instagram получили собственные SVG-пиктограммы и аккуратную сетку.
8. Восстановлена мягкая инерционная прокрутка колёсиком на десктопе с мышью. Скролл тачпадом, на мобильных и перетаскиванием системной полосы остаётся нативным.
9. Убраны стрелки с emoji variation selector; используется обычный типографский символ «→». Улучшена мобильная адаптация на узких экранах.
10. Сайт показывает загрузочную заставку только один раз за браузерную сессию, чтобы переходы между настоящими HTML-страницами не затягивались.

## Где какие файлы

- `index.html` - главная.
- `catalog.html` - все товары, поиск и фильтры.
- `product/NNN.html` - отдельная страница каждого из 121 ароматов, где NNN - исходный номер с тремя цифрами (например `product/015.html`).
- `product.html?id=N` - запасной адрес для товаров, добавленных позднее через подключённую админ-панель (без ручной генерации HTML).
- `quiz.html` - анкета подбора.
- `about.html` - о бренде; `selection.html` - искусство выбора.
- `info.html` - оплата и доставка; `contacts.html` - контакты.
- `privacy.html` - политика обработки персональных данных.
- `admin.html` - защищённая панель после подключения сервера.
- `assets/products/` - 121 фотография в WebP.
- `assets/backgrounds/` - декоративные изображения.
- `assets/app.js` - интерфейс, каталог, корзина, формы.
- `assets/v10.css` - изменения дизайна и адаптации.
- `backend/worker.js` или `backend/worker.mjs` - заготовка Cloudflare Worker.

**Размещать нужно всё содержимое папки, сохраняя структуру.** Для GitHub Pages: добавить все файлы в репозиторий, настроить Pages, затем открыть домен. Для проверки на компьютере также подойдёт простой локальный HTTP-сервер. При открытии отдельных HTML в некоторых мобильных файловых приложениях JavaScript или относительные ссылки могут быть ограничены самим просмотрщиком.

## Админ-панель: как пользоваться после подключения

Сейчас административная панель в режиме предпросмотра **не активирована**: `window.LAV_CONFIG.apiBase` в HTML пустой. Ни логина, ни рабочего сервера, ни реальной отправки заявок этот архив не предоставляет. Чтобы включить:

1. Развернуть `backend/worker.js` в Cloudflare Workers.
2. Привязать пространство **KV** под именем `LAV_KV` для товаров, заказов и настроек; **R2** под именем `LAV_IMAGES` для загружаемых изображений.
3. В переменных/Secrets настроить `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `TOKEN_SECRET`, `SITE_ORIGIN`. Для уведомлений - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; для защиты форм - `TURNSTILE_SECRET`.
4. Во всех входных HTML-файлах прописать `window.LAV_CONFIG={apiBase:'https://АДРЕС-WORKER',turnstileSiteKey:'ПУБЛИЧНЫЙ-КЛЮЧ'}` с реальным доменом Worker (значения должны быть согласованы с настройкой CORS/SITE_ORIGIN). Пароль никогда не помещать в HTML или JavaScript клиента.
5. Открыть `https://ДОМЕН-САЙТА/admin.html`, войти учётными данными. Нажать «Изменить» рядом с товаром: можно править название, бренд, описание, ноты, цены 3/5/10 мл и целого флакона, фотографию, а также публикацию, новинку, хит. После сохранения сервер отдаёт обновления покупателям. Для нового товара нажать «Добавить аромат», заполнить форму и опубликовать.
6. В разделе настроек можно менять адрес, часы, ссылки мессенджеров, текст о бренде, оплате и доставке. В «Заказах» можно просматривать заявки и менять их статус, в «Анкетах» - просматривать ответы на подбор.

Для рабочей версии обязательны отдельные проверка подключения Worker, авторизации, загрузки изображений, обработки заявок и юридических текстов. На момент передачи архив - рабочий фронтенд и серверная заготовка, **не запущенный магазин с функционирующим бэкендом**.

## Проверка

- Проверены связи файлов: 121 видимый товар -> 121 HTML-страница -> существующее изображение.
- JavaScript проходит `node --check`. Предпросмотр с инлайн-ресурсами проверен в Chromium при ширинах 320, 390, 768, 1440 пикселей: разметка каталога, Louis Vuitton Imagination, анкета, контакты и доставка; критических ошибок JS и горизонтальных выходов за экран не обнаружено.
- Левая колонка анкеты дополнительно проверена при прокрутке: при `scrollY=1350` верхняя граница остаётся на 92px на настольном экране.

Версия 9 оставлена отдельно, исходные товарные данные (цены, описания и 121 активная позиция) не удалены и не переписаны, кроме восстановления фото №015.
