# Лав парфюм - v13: согласованные визуальные и редакторские правки

Взята версия v12; сохранено обновление пирамид нот из файла products.js, который ранее передавался клиенту.

Изменено:
- 121 фото просмотрены по контактным листам. Из них три карточки (№32 Dries Van Noten Fleur du Mal, №50 Lattafa Art of Nature II, №53 Nishane Hacivat) переведены на реальные полные товарные фотографии из публичных карточек интернет-магазинов. За счёт этого восстановлена крышка №32, вместо коробок №50 и №53 показаны флаконы. Важно: ссылки внешние, зависят от доступности сайтов-источников. Это не генеративные картинки.
- Главная обложка теперь использует оригинальную предоставленную фотографию IMG_4742.JPG (без замены флакона и без рисования). Только первый экран изменён.
- Коллекция отсортирована по алфавиту брендов A-Z, внутри бренда - по алфавиту ароматов. Фильтры и поиск работают в этом порядке.
- Тексты разделов написаны от первого лица владельца, тёплым и личным тоном. Данные юридического характера сохранены.
- На странице оплаты и доставки добавлен компактный блок обмена и возврата, отражающий права покупателей. Категорический запрет возврата без исключений для онлайн-заказов в России был бы недостоверен.
- Разработка API, корзины и админ-панели не входила в эту серию правок, их не подключали.

Изменённые общие файлы: assets/app.js, assets/products.js, assets/products.json, assets/v12.css; добавлен assets/backgrounds/home-owner-photo.webp.
Все HTML-файлы остались без изменений. Другие изображения и фоны НЕ менялись.

Сайт публикуется содержимым папки целиком в корень GitHub Pages.
Для обновления действующего сайта используйте архив «lav_parfum_v13_tolko_izmeneniya.zip»: распакуйте в корень репозитория с заменой файлов и отправьте изменения через GitHub Desktop.
Существующие assets/products/*.webp сохранены без изменений.
