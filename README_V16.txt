LAV PARFUM V16 - полный сайт.

Изменения:
- Восстановлены оригинальные 121 фотографии флаконов из V13 вместо обработанных алгоритмом удаления белого фона V14. Оригинальные цвет и этикетки сохранены.
- Пять товарных фотографий обновлены из шести присланных пользователем файлов. Шестой файл содержит изображение ароматных нот рядом с флаконом, поэтому он использован для выделения зоны флакона, а не как отдельный товар. Также обновлено изображение Dries Van Noten Soie Malaquais (id 63).
- Для всех шести фотографий выполнена только прямоугольная обрезка внешнего фона и масштабирование без ретуширования флаконов. На фотографии Symphony исходный интерфейс скриншота отрезан прямоугольной обрезкой.
- Восемь новых авторских фотографий использованы как фоновые/журнальные акценты вместо старых декоративных фонов.
- Добавлена одна журнальная секция, сохранена существующая палитра, навигация, каталог, функциональность.
- Удалён кастомный перехват колёсика мыши, восстановлен естественный скролл.
- Защита от выхода текста за границы на узких экранах.
- Блок обмена/возврата из V15 без юридической приписки, уменьшен.

ВАЖНО: изображения не проходили ретуширование белых бликов внутри самого флакона: это потребовало бы изменения бутылки, что пользователь запретил. Оригинальные блики на стекле могут сохраняться.
