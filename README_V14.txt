ЛАВ ПАРФЮМ — ПОЛНАЯ ВЕРСИЯ V14

Это полный сайт, распаковывать в корень локальной папки репозитория lav-parfum-site, сохраняя структуру папок.

Что изменено:
1. Для всех 121 локальных товарных фотографий проведён аудит белого фона. У 115 фото фон аккуратно отделён от флаконов с сохранением закрытых светлых деталей. 6 белых/прозрачных флаконов оставлены в оригинале, поскольку автоматическое удаление уничтожало части самого предмета (020, 059, 073, 080, 090, 109). Возможные исходные отражения стекла сохранены: они являются частью фотографии, а не фоном.
2. Проверены 7 указанных флаконов: 005, 015, 027, 028, 036, 060, 083. Созданы прозрачные края без обрезания крышек, этикеток и корпуса.
3. Новый векторный монограммный логотип LP: assets/logo-lp-v14.svg, подключён ко всем страницам.
4. Страница «Оплата и доставка»: раздел условий покупки оформлен по присланному тексту и образцу. Уточнение о законных правах покупателей сохранено отдельно.
5. Более мягкая прокрутка на десктопе, деликатные анимации и тёплый бежевый фон, CSS assets/v14.css.
6. Структура, содержимое каталога и статические страницы товаров сохранены.

Установка через GitHub Desktop:
- Откройте Repository > Show in Explorer.
- Распакуйте содержимое архива в эту папку с заменой файлов.
- Вернитесь в GitHub Desktop: Commit to main > Push origin.
- Дождитесь зелёного успешного статуса публикации GitHub Pages (Actions), затем откройте сайт с Ctrl+Shift+R.

Ограничения:
- Автоматическое устранение фона не равнозначно профессиональной ретуши стеклянных отражений. Некоторые естественные отблески на флаконах сохранены во избежание потери деталей.
- В архиве исходно 123 товара, из них 121 локальное фото; внешние изображения зависят от источников.
- Живой браузерный визуальный тест в этой среде не выполнен; выполнены проверки структуры, JS и связей статических ресурсов.
